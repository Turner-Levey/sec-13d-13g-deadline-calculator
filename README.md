# Schedule 13D / 13G Deadline Calculator

Free no-tracking Schedule 13D and 13G deadline calculator for common beneficial ownership reporting scenarios:

- Schedule 13D initial filings.
- Schedule 13D material amendments.
- Schedule 13G QII / exempt investor quarter-end scenarios.
- Schedule 13G passive investor initial filings.
- Accelerated Schedule 13G amendment scenarios.

The tool runs entirely in the browser. It has no signup, cookies, analytics, beacons, external scripts, uploads, or browser storage.
